the CLI. A chronological chat keeps requests, results and run activity together,
including after returning from a coding agent, and saves a local session transcript.

run count and enabled integrations remain visible below the input.

a suggestion before Enter submits it. The main input handles navigation and tasks,
with no separate request shortcut. Keyboard help fits a single terminal row.
