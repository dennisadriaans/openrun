You no longer have to start a fresh conversation when the work already lives
in a local Claude, Codex, Grok, or Antigravity chat. The new-automation form
lists the recent native sessions for each installed CLI next to the project
picker — five per binary, with load more for older ones — and the first turn
resumes that chat instead of minting a new one. Native chats stay out of Runs
until Open Run actually drives a turn. The workspace folder must be the same
cwd the CLI used.
