You no longer have to restart the CLI to choose another action or abandon a
selection. Running `openrun` opens a persistent OpenTUI Home with one request
input above inline live counts for running, scheduled and automation work. Use the `integrations` and
`runs` commands to see connections and recent runs.
Home buttons open scheduling, recent runs and integrations with a click.
Complete schedule requests submit directly. Run activity updates in place,
including work started in another terminal. Escape goes back through menus and
setup steps; Tab switches to scrollable output. Type `quit` or press
Ctrl+C twice to leave. The interface uses Bun 1.3+ or Node.js 26.4+; scripts
and the background worker continue to support Node.js 22.12+.
Guided scheduling labels its final action Confirm schedule.
