You no longer stall navigation or API calls when several run tabs stay open with
live streams. The app-wide activity stream closes on run detail pages, run
streams pause in background tabs, and stale SSE sockets tear down when a tab
navigates away.

You no longer need to hover to hide models and runtimes in the composer — the
eye toggle stays visible for touch and keyboard, runtime icons resolve from the
wrapper id when the binary name is generic, and the send menu offers queue-now
while a run is already going.

of only name, runtime, and prompt.
