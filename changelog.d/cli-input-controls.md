You no longer lose selected input when copying it in the terminal. Ctrl+A
selects all, Ctrl+C copies the selection, and Ctrl+V pastes at the cursor.
Selection is visible, and pasted lines are separated by spaces.

You no longer need to put runtime, model and effort in a fixed order. Requests
such as `create new file test-123123.html with contents '123' claude sonnet low`
and `low create new file test-123123.html with contents '123' sonnet claude`
select the same agent settings while preserving the quoted contents.
