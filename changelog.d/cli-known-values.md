You no longer get asked for the agent, model and effort when a timed request ends
with a model name, such as `create foo.html in 10 seconds haiku`. The model is
recognized locally, including the common misspelling "heiku".

You no longer retype a task or a time you already gave. The terminal only asks
for values that are missing or unreadable, so a complete request is scheduled on
the first Enter instead of stopping at a prefilled question.
