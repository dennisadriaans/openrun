- Verification checks no longer hijack a conversation. Sending a message on a run detail page used to kick off the project's full check pass — `pnpm typecheck`, `pnpm test`, the lot — with the run held `running` and the workspace locked until it finished, before you could type again. Checks now run on unattended turns only: the automation's own turn and its repair turns. Chat, Planner and any follow-up you type finish the moment the agent does.
- Checks themselves are leaner. The per-check **Blocking** toggle is gone — every check gates, and an advisory check that changed nothing was never worth configuring — as is the per-check **Timeout** field, replaced by one 10-minute budget. `build` is no longer suggested from `package.json`; it is slow and typecheck already covers what it would catch.
