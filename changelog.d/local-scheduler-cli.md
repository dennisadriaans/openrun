You no longer need the browser to schedule an agent. `openrun schedule for claude at 16:40 "create new homepage with contactform" push and open a pull request` reads the runtime, the time, the workspace you are standing in and the ask, then arms it on the same local scheduler the Automations page uses — and `openrun ls`, `now`, `enable`, `disable`, `rm` and `run` cover the rest without leaving the terminal. `--dry-run` shows exactly what it would create before anything is written, and a line it cannot read says which part it choked on instead of guessing at a time. - Non-browser clients can now authenticate: the access token is accepted as `Authorization: Bearer`, which is what the generated fetch client, the new CLI and the Apple package have always sent.
