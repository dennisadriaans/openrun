You no longer have to keep the Activity panel open in the CLI. The Activity
button next to the connection status hides it, and the chat takes the full
width. Activity rows now fit on one line: status, time, prompt and file
changes. Model and effort moved to the run's detail page, and a scheduled or
started task now appears right under the prompt that asked for it, with its
live status, when it fires, the model and the effort.
