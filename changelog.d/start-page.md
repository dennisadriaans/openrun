Opening Open Run no longer drops you on the automations list. The home screen is
now a start page: the same composer the run detail uses, the project and branch
pickers, and the resume dropdown that lists the chats each CLI already has in
that branch — so a message, a resumed Claude or Codex session, and a scheduled
automation all begin in one place. Six automation shortcuts (review open pull
requests, fix failing checks, update dependencies, triage new issues, cover
untested logic, refresh the docs) open the automation form already filled in and
switched off, ready to review.
